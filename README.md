# OmniFood Responsive Food Delivery Landing Page

Open `index.html` in a modern browser to view the responsive OmniFood food-delivery landing page. The project uses HTML and CSS, with the Poppins font loaded from Google Fonts and external image URLs for food, city, and customer imagery.

## Sections

- Hero and navigation
- How it works
- Cities
- Customer testimonials
- Pricing plans
- Footer

The layout uses Flexbox, CSS Grid, and responsive media queries for desktop, tablet, and mobile screens. No build step is required.
